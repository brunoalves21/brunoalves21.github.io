Privacy Policy

Last updated: 2025

Finance Agent is a personal tool used only by its author, Bruno Silva. It is not distributed to or used by anyone else.

Data accessed

With the author's explicit consent via Google OAuth, the app reads messages and attachments from the author's own Gmail account in order to identify invoices, receipts and payment notices.

How data is used and stored

  • Data is used solely for the author's personal bookkeeping.
  • Data is stored locally on the author's own computer.
  • Data is never sold, shared with, or transferred to third parties.
  • Data is not used for advertising or any other purpose.

Google API Services

Finance Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
